## How posts work

Each post is one Markdown file in `content/posts/`, with a little frontmatter at the top:

- `title` and `date` are required. Use `YYYY-MM-DD` for the date.
- `excerpt` is optional. If you skip it, the first sentence of the post is used.
- `tags` is an optional list.
- `slug` is optional. By default it comes from the filename.
- `draft: true` keeps a post out of the build while you work on it.

Run `npm run build` and the finished site appears in `dist/`.
